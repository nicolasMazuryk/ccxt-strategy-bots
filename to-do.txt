Build a trading strategy called “wick-bot.”
The example below describes how it operates for LONG positions, but the strategy is designed to work in both LONG and SHORT directions.
	
1.	Identify historical wick-downs at local lows.
“Historical” refers to all candles excluding the current candle.
If there are multiple wicks at the local low - Take into account only the lowest wick.


2.	If the price on the current candle drops below the end of a historical wick, and then reverses back up to that wick end, open a LONG position.
3.	The stop-loss is set at the low of the current candle.
The take-profit is set at a 2:1 risk/reward ratio — calculated as twice the distance between the entry price and the stop-loss.
4. Identified historical wick level can only be triggered once.


Define variable names for the following parameters:
	1.	max_historical_candle_lookback – The max number of candles between the current candle and historical candle. Candles outside this window is ignored.
    1.	min_historical_candle_lookback – The min number of candles between the current candle and the first historical candle. If set to 0, the first previous candle from the current one is a qualifying candle used as the historical reference.
	2.	min_historical_wick_size – The minimum wick size (in percentage) used to qualify a candle as having a valid wick. This is the distance from the wick end to the candle body.
	3.	min_current_wick_size – The minimum difference (in percentage) between the end of the historical wick and the low of the current candle that later reverts back to the wick end. This acts as a validation check for entry conditions.
